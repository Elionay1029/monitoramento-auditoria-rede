# Monitoramento e auditoria de rede com Python

**Projeto pessoal de portfólio | 2026**

- Desenvolvi um inventário de portas TCP com Python, comparação de hosts e serviços com uma baseline JSON e regras de alerta com evidências e sugestões de mitigação.
- Implementei análise offline de arquivos PCAP com Scapy, identificação de padrões TCP SYN e conflitos IP/MAC, relatórios HTML, JSON e CSV e testes automatizados com dados sintéticos e loopback.

O projeto foi criado para demonstrar conhecimentos técnicos em um laboratório. Os dados de demonstração são fictícios; a descrição não representa auditorias profissionais, operação em produção ou certificação ISO/IEC 27001.
